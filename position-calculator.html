What it does

Single-shot lock

Once a trade fires, a flag stored by the MT5 terminal itself keeps it from ever opening another — surviving removing the EA, closing the chart, even a full restart of MT5.

Risk-based sizing

You set a risk percentage and a stop-loss price; the lot size is calculated from that, then rounded to whatever step, minimum, and maximum your broker actually allows.

Take-profit from R:R

Set a risk:reward ratio and the take-profit price is calculated automatically from your stop-loss distance.

Pre-trade checks

Validates that your stop-loss sits on the correct side of price for the direction chosen, confirms there's enough free margin, and asks for manual confirmation if risk exceeds a threshold you set.

Trading-permission aware

Checks the toolbar AutoTrading button, this EA's own Algo Trading permission, and the account's trading permission. If any is off when you attach it, it keeps watching and fires automatically the moment you switch it on.

Install

  1. Download RiskRR_AutoTrade_EA.mq5 below.
  2. In MT5, open MetaEditor (press F4), then use File → Open and browse to your MQL5/Experts folder — or find it faster via MT5's File → Open Data Folder.
  3. Place the downloaded file in that Experts folder, then open it in MetaEditor and compile with F7.
  4. Back in MT5, refresh the Navigator panel (right-click → Refresh) and find it under Expert Advisors.
  5. Drag it onto a chart. Fill in Direction, Stop Loss Price, Risk %, and R:R in the Inputs tab.
  6. Make sure the toolbar AutoTrading button is on, and Allow Algo Trading is checked in the Common tab — the EA will tell you if either is missing.
